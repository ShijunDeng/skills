# Email — 邮件发送

> 零外部依赖，配置驱动，发送前强制确认。

---

## 流程总览

```
┌───────────────┐    ┌───────────────┐    ┌───────────────┐    ┌───────────────┐    ┌───────────────┐
│  Step 1       │    │  Step 2       │    │  Step 3       │    │  Step 4       │    │  Step 5       │
```

## Step 1: 内容获取

### 识别内容来源

| 场景 | 用户表述示例 | 处理方式 |
|------|-------------|---------|
| **直接输入** | "发邮件给 xxx，主题是 A，内容是 B" | 从当前消息提取主题和正文 |
| **转发对话** | "把刚才的输出发到 xxx"、"转发上一条回复" | 从对话历史提取模型输出作为正文 |
| **仅触发** | "帮我发邮件"（无具体内容） | 引导用户逐步提供主题、正文 |

### 内容提取规则

**主题**：
- 用户明确指定 → 直接使用
- 未指定 → 根据正文生成简洁主题（≤50字符）
- 转发场景 → `[转发] {内容摘要前30字}`

**正文**：
- 直接输入 → 用户提供的完整内容
- 转发对话 → 模型输出的完整文本，保留原始格式

### 内容确认

提取后展示预览：

```
📧 邮件内容已准备：

主题: {subject}
正文预览: {body前80字符}...

回复 "确认" 继续，或告诉我要修改的内容。
```

## Step 2: 配置检查

### 配置文件位置

`email/config/email-config.json`（相对于 skill 根目录）

### 必填字段

| 字段 | 说明 |
|------|------|
| `sender_email` | 发件人邮箱 |
| `sender_password` | 密码/授权码 |

### 可选字段（有默认值）

| 字段 | 默认值 | 说明 |
|------|--------|------|
| `smtp_host` | `smtpscn.huawei.com` | SMTP 服务器地址 |
| `smtp_port` | `25` | 端口（SSL: 465, STARTTLS: 587） |
| `smtp_use_ssl` | `true` | 是否 SSL 连接 |

### 检查流程

1. 检查配置文件是否存在
2. 验证所有必填字段是否已填写
3. 根据状态执行对应操作：

| 状态 | 处理 |
|------|------|
| 文件不存在 | 引导用户创建配置 |
| 必填字段为空 | 列出缺失字段，逐项引导填写 |
| 配置完整 | 继续下一步 |

### 配置引导

当配置缺失时：

```
⚠️ 邮件配置不完整，请提供以下信息：

缺失: {missing_fields}

常用 SMTP 配置：
| 邮箱       | smtp_host          | port | SSL  |
|-----------|-------------------|------|------|
| Gmail     | smtp.gmail.com    | 465  | true |
| Outlook   | smtp-mail.outlook.com | 587 | false |
| QQ邮箱    | smtp.qq.com       | 465  | true |
| 163邮箱   | smtp.163.com      | 465  | true |

请提供：
1. SMTP 服务器地址
2. 端口号
3. 是否使用 SSL（是/否）
4. 发件人邮箱
5. 密码（建议使用应用专用密码）
```

用户回复后，将配置写入文件，然后继续流程。

## Step 3: 收件人确认

### 收件人来源优先级

1. 用户本次明确指定 → 使用指定值
2. 配置文件中的 `default_to` → 使用默认值
3. 两者皆无 → 引导用户输入

### 确认界面

```
📬 收件人信息：

To: {to_list}
Cc: {cc_list 或 "无"}
Bcc: {bcc_list 或 "无"}

回复 "确认" 使用当前收件人，或告诉我新的地址。
```

### 邮箱格式验证

规则：`local@domain.tld`
- 必含且仅含一个 `@`
- `@` 前后均有内容
- 域名含至少一个 `.`

格式错误提示：`⚠️ 邮箱格式不正确: {email}`

## Step 4: 发送前确认

### 最终预览（强制展示）

```
═══════════════════════════════════════
📧 邮件发送确认
═══════════════════════════════════════

发件人: {sender_display_name 或 sender_email}
收件人: {to_list}

主题: {subject}

正文:
───────────────────────────────────────
{body}
───────────────────────────────────────

请确认：
- 回复 "确认" 或 "发送" → 发送邮件
- 回复 "主题: 新主题" → 修改主题
- 回复 "正文: 新内容" → 修改正文
- 回复 "取消" → 终止发送
```

### 用户操作处理

| 用户输入 | 处理 |
|---------|------|
| 确认/发送 | 执行 Step 5 |
| 主题: xxx | 更新主题，重新展示预览 |
| 正文: xxx | 更新正文，重新展示预览 |
| 取消 | 终止流程，不发邮件 |

## Step 5: 执行发送

### 调用脚本

```bash
python refs/email-sender.py \
  config/email-config.json \
  --subject "{subject}" \
  --body "{body}" \
  --to "{to_emails}"
```

### 结果处理

| 结果 | 响应 |
|------|------|
| 成功 | ✅ 发送成功 + 更新配置中的收件人 |
| 认证失败 | ❌ 提示检查密码/授权码，引导重配置 |
| 连接失败 | ❌ 提示检查 SMTP 地址/端口 |
| 其他错误 | ❌ 展示错误，提供排查建议 |

### 成功响应

```
✅ 邮件发送成功！

发件人: {sender_email}
收件人: {to_list}
主题: {subject}

收件人已保存为默认值，下次发送自动使用。
```

```json
{
  "smtp_host": "smtpscn.huawei.com",

  "smtp_use_ssl": true,
  "sender_email": "user@example.com",
  "sender_password": "app-specific-password",
  "sender_display_name": "Your Name",
  "default_to": ["recipient@example.com"],
  "default_cc": [],
  "default_bcc": []
}
```

## 错误处理速查

| 错误 | 原因 | 解决 |
|------|------|------|
| SMTPAuthenticationError | 密码错/未开 SMTP | 检查应用专用密码 |
| SMTPConnectError | 地址/端口错 | 确认 SMTP 配置 |
| timeout | 网络问题 | 检查网络连接 |

---

## 安全提醒

- `email-config.json` 应加入 `.gitignore`
- 使用应用专用密码而非账户主密码
- 不在对话中展示完整密码
